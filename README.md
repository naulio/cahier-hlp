# Cahier d'HLP · Terminale

**➜ https://naulio.github.io/cahier-hlp/**

Un cahier de révision pour la spécialité **Humanités, littérature et philosophie** (Terminale), pensé pour toute la classe :

- une **fiche par texte** : l'essentiel en cinq points, l'auteur, l'époque, le mouvement, l'œuvre, les procédés, les citations, les notes de cours ;
- des **flashcards** à répétition espacée (boîtes de Leitner) ;
- des **QCM corrigés et expliqués**, qui insistent sur les points faibles, et un **examen blanc** chronométré ;
- pour relier les textes : **frise chronologique**, **carte des positions**, **duels**, **radars**, **palais de mémoire** ;
- un **mode oral**, des **textes à trous**, « **Qui a dit ?** », les **exercices du manuel** avec corrigés.

Gratuit, sans compte, sans publicité. La progression est enregistrée dans le navigateur de chacun (rien n'est envoyé).
Les chapitres sont ajoutés au fil de l'année.

Les textes étudiés ne sont pas reproduits (droits d'auteur) : garde tes feuilles distribuées en classe.

## Structure

- `lecons/` : un fichier par chapitre (format décrit dans `lecons/_modele.js`)
- `app/` : le moteur de l'application
- `outils/verifier.mjs` : vérification des leçons avant publication (`node outils/verifier.mjs`)
